# 판매자 수수료 도구 · shakilabs

**▶ 라이브 서비스: <https://shakilabs.com/seller>**

오픈마켓·결제 서비스·택배 수수료를 한 화면에서 비교하는 온라인 판매자 도구.

## 주요 도구

- [오픈마켓 수수료 비교](https://shakilabs.com/seller/market-compare)
- [결제 수수료 비교](https://shakilabs.com/seller/payment-compare)
- [택배비 비교](https://shakilabs.com/seller/shipping-compare)

전체 서비스 12종: <https://shakilabs.com>

## 스택

Vue 3 (Composition API) · TypeScript · Vite · Tailwind CSS · 공유 UI `@shakilabs/ui`
정적 프리렌더/SSG로 배포하며, 계산 로직은 Vitest 경계값 테스트로 검증합니다.

## 개발

```bash
cd client
npm install
npm run dev
```
